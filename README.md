# PH-A1 — Landing Launchpad

A responsive landing-page assignment built from a supplied design while practicing HTML and CSS fundamentals.

## Live demo

https://taoshif1.github.io/PH-A1/

## Highlights

- Responsive hero section
- Productive-user statistics
- Testimonial cards
- Call-to-action section
- Contact form
- Responsive footer
- Google Fonts
- Desktop and mobile layouts

## Tech stack

- HTML5
- CSS3

## Run locally

No build tools are required.

```bash
git clone https://github.com/Taoshif1/PH-A1.git
cd PH-A1
```

Open `index.html` in your browser.

## Design resources

The repository includes the original assignment/design assets under `B12A01-landing-launchpad`.
